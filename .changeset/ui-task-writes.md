Let the UI role write the task records the panels save: create and update on tasks, comments, and assignments; create on tag links, tags, roles, decisions, and activities; delete on assignments and tag links. The list and board reload when their filter changes, and the list indents by depth. TaskClicked stays the task id. TaskRowClicked carries the id and name. The edit panel reads the People id from metadata before it saves, accepts a parent-list filter, and reports a refused save.
