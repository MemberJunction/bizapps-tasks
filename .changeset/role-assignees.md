A task can be assigned to an MJ role: a Task Assignment with `AssigneeEntityID` = `MJ: Roles` lists the task in every holder's My Tasks and approval inbox, notifies each active holder, and lets any holder decide an approval. The approval inbox also names and links the records each task is linked to, and takes `Title`, `EmptyText`, `ApproverRoleIDs` and `ShowLinkedRecords` inputs.
